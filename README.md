# VR Game Planning Example

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **Vital Point** |
| 장르 | VR / Action / Hunting |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | First Person |
| 예상 플레이 시간 | 30분 |

### 한 줄 소개
> VR에서 활을 이용한 사냥게임

---

## 2. 게임 컨셉

총을 구하기 힘든 아포칼립스 세계에서 플레이어는 쉘터(은신처)의 일원으로서 활을 이용하여 

사냥하며 식량을 구하고 그 부산물을 이용하여 쉘터와 거래 및 일정량 목표를 달성하면서 게임을 클리어한다.

### 핵심 키워드

- **Explore** : 사냥할 동물 탐색
- **hunting** : 은신하여 활로 동물 사냥
- **Collect** : 사냥한 동물 전리품 획득
- **Attainment** : 목표량 달성 및 게임 클리어

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 자연 필드에서 탐색한다
2. 등장하는 동물을 발견한다.
3. 동물을 추적하고 사냥한다.
4. 전리품으로 고기 획득한다
5. 쉘터로 돌아간다.
6. 고기를 반납하고 목표치 달성하여 게임 클리어

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
탐색
  ↓
동물 발견
  ↓
추적 및 사격(활)
  ↓
동물 처치
  ↓
아이템(고기) 획득
  ↓
거점 구역 이동
  ↓
아이템(고기) 제출 및 목표 달성
  ↓
클리어
```

플레이어는 게임이 종료될 때까지 **탐색 → 추적/사냥 → 아이템 획득 → 이동**의 과정을 반복한다.

## 5. 플레이어 조작(오큘러스 퀘스트 컨트롤러 기준)

| 입력 | 기능 |
|---|---|
| L stick | 이동 |
| R stick | 시점 전환 |
| L/R HandTrigger | 물체 잡기 |
| A | 상호작용 |
| L stick press  | 달리기 |
| x | 옵션 메뉴 |
| Y | 인벤토리 메뉴 |

---

## 6. 플레이어 기능

플레이어는 1인칭 시점으로 맵을 자유롭게 이동할 수 있다.

주요 기능 방식:

-컨트롤러를 해당 위치로 이동하여 트리거를 누르면 활과 화살이 손에 잡히는 형식
(화살통를 허리춤에 배치 활은 등 뒤쪽에 배치, 화살통에서 화살의 개수를 시각적으로 파악 가능)

-활은 왼손은 활 오른손은 화살을 쥐어 화살을 활에 갖다대어 오른손을 뒤로 당기면서 발사하는 형식

-그외에 상호작용은 좌/우측 컨트롤러(오른손)의 방향으로 갖다대어 사용하는 형식
